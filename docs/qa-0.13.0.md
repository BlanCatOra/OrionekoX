# QA — alpha 0.13.0（从背景自动配色）

- 版本：`0.13.0`，versionCode **1439**
- 设备：emulator-5554（1080×2400，Android 14/34，`-gpu off`）
- 时间：2026-10-27 20:38–20:47（CST）
- 目标：实现“壁纸与气泡联动/动态取色”创新项：从当前背景图或渐变取平均色，自动生成可读的收发气泡、文字、边框和暗化。

## 1. 算法

- 背景为图片：采样到不超过 64px（2 的幂 inSampleSize），跳过 alpha<32 的像素，按 RGB 求平均。
- 背景为渐变：两张色 50% 混合；纯色直接取背景色。
- 由平均色生成：
  - 收气泡 = 平均色向白色混合 84%（暗背景）/ 94%（亮背景）
  - 发气泡 = 提高饱和度后的平均色向白色混合 62%（暗）/72%（亮）
  - 文字色 = 根据收/发气泡平均亮度自动取深色或白色
  - 边框 = 发气泡混黑/白 28%，1dp
  - 暗背景自动加 60/255 暗化；气泡为实心、不透明（alpha 255）、16dp 圆角
- 只改当前作用域（全局或 Agent），不改预设文件与背景图本身。

## 2. 设备验证

- 将 `verify-rice.jpg`（深蓝底、洋红边框）设为背景，点“从背景自动配色”。
- 外观页生成：
  - 收气泡 `#DCDDE5`
  - 发气泡 `#A3A6C2`
  - 边框 `#BDBFD3`
  - 文字为深色（页面显示自动对比）
  - 背景仍为所选图片（`#000000` 基色 + 图片 + 暗化 60）
- 打开 R2C Card：背景为所选深蓝图片并带暗化，收气泡浅灰蓝、文字深色可读，边框为细灰蓝；无红叹号/崩溃。
- 截图：`/tmp/auto-palette.png`、`/tmp/auto-palette-chat.png`。

## 3. 边界与未覆盖

- 极亮或极暗单色背景只做了代码路径推演；设备实测为深蓝图片。
- 半透明 PNG 的 alpha 采样已跳过，未单独构造样本。
- 从背景图取色时不会自动替换背景图；用户可先清除图片再套用纯色。
- 无 FATAL/ANR。
