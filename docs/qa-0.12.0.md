# QA — alpha 0.12.0（内置主题一键套用 + 文字色修复）

- 版本：`0.12.0`，versionCode **1429**
- 设备：emulator-5554（1080×2400，Android 14/34，`-gpu off`）
- 时间：2026-10-27 20:15–20:32（CST）
- 目标：补齐竞品“预设市场 / 一键套用”缺口，并修复自定义文字颜色被 `ChatMessageCell` 主题色覆盖的问题。

## 1. 新增能力

- 外观页新增“内置主题 · 一键套用”六款：
  | 名称 | 背景 | 收/发气泡 | 文字 | 边框/圆角 |
  |---|---|---|---|---|
  | 午夜墨黑（AMOLED） | #000000 | #121212 / #1E1E1E | #FFFFFF | #333333 · 14dp |
  | 纸墨 | #F7F3E8 | #FFFFFF / #E8F0D8 | #1A1A1A | #D8D0C0 · 12dp |
  | 深海 | 渐变 #0B1E3A→#123A5A | #16324F / #1F6F8B | #EAF6FF | #2A5A7A · 18dp |
  | 樱花 | #FFF1F5 | #FFFFFF / #FFE0EC | #3A1F2B | #F2C6D6 · 20dp |
  | 森林 | #0F1F17 | #173326 / #2E5D3A | #EAF7EE | #3E6B4D · 16dp |
  | 赛博霓虹 | 渐变 #0A0014→#1B0033 | #1B0033 / #7C00FF | #00F0FF | #FF2D95 · 2dp · 8dp |
- 一键套用写入当前作用域（全局或单个 Agent），只覆盖外观快照，不动预设文件、记忆、工作区。
- 文字色修复：`ChatActivity.ThemeDelegate` 新增 `oxTextColor`，在 `getColor(key_chat_messageTextIn/Out)` 时优先返回自定义文字色；`OxChatTheme` 应用/恢复时设置/清空。此前 `ChatMessageCell` 在绘制时会把文字色重置回主题色。

## 2. 设备验证

### 2.1 赛博霓虹 — PASS

- 应用后外观页显示：`双色渐变`、`#0A0014`、`#1B0033`、收 `#1B0033`、发 `#7C00FF`、边框 `#FF2D95` 2dp、文字 `#00F0FF`、圆角 8dp。
- 打开无 Agent 覆盖的 R2C Card：背景为紫黑渐变、气泡带洋红 2dp 边框、文字为青色 `#00F0FF`，与设置一致。

### 2.2 午夜墨黑 — PASS

- 应用后打开 R2C Card：纯黑背景、深灰收气泡、白色文字、`#333333` 细边框，状态栏/导航栏同步黑色。
- 原文字色缺陷修复前，赛博主题文字显示为黑色；修复后同一会话显示青色。

### 2.3 按 Agent 覆盖优先级 — PASS（有测试数据说明）

- C2 仍使用其早先保存的浅色 Agent 覆盖（背景 #F3F1F7、收气泡 #FFFFFF），没有被全局 AMOLED 覆盖。
- 该覆盖同时保留了当时设置的白色文字，形成白底白字；这是旧测试快照内部不一致，不是 0.12.0 回归。内置主题与新建覆盖均写入成套配色；外观页“检查文字对比度”可发现此类问题。QA 后已把 C2 覆盖重置为跟随全局。

## 3. 未覆盖

- 六款内置主题只逐项验证了赛博与 AMOLED 的完整视觉，其余四款仅检查代码字段。
- 内置主题在 Agent 作用域下的一键套用（与全局共用 `applyBuiltIn → persist`，未单独截图）。
- 预设导入/导出、`.oxtheme` 资产包在 0.11.0 已验证，本轮未重复。
