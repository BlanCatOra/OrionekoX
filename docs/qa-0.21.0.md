# QA — alpha 0.21.0（外观编辑器实时预览）

- 版本：`0.21.0`，versionCode **2109**（`0.20.0` 为 2009）
- 设备：emulator-5554（1080×2400，Android 14/34，`-gpu guest` 软件渲染）
- 时间：2026-10-28 01:10–01:22（CST）
- 目标：补齐竞品“外观编辑器实时预览”缺口：在自定义外观页直接预览当前
  作用域的背景、气泡、边框、字体与行高，不再需要返回聊天页才能看到效果。
- 版本规则：新增一项可见的编辑器能力，按 minor 从 0.20.0 → **0.21.0**，
  versionCode 2109（210×10+9）。

## 1. 新增能力

- 自定义外观模式下，外观页在“外观模式”下方新增“预览当前外观”行。
- 点击后打开原生 `AlertDialog`，内容包括：
  - 当前作用域的壁纸层（纯色/渐变/图片，含背景不透明度、暗化与背景模糊）；
  - 一条收到的示例气泡、一条发出的示例气泡；
  - 收/发气泡色、透明度（磨砂时与聊天一致压到 200/255）、圆角、边框色/宽度；
  - 文字色（未指定时按气泡亮度自动选黑/白）、聊天字体（若导入 TTF）、
    字号倍率与行高倍率。
- 预览直接读取 `OxChatTheme.current()`，因此全局、按 Agent、按会话三种作用域
  都显示各自当前值；原生模式不显示该行。
- 新增 `OxChatTheme.currentBackgroundDrawable()` 与 `currentTypeface()`，复用
  聊天页同一套背景/字体构建逻辑。

## 2. 设备验证 — PASS

当前全局外观：自定义、图片背景 `ox_chat_bg`、模糊关、1.15× 字号、1.4× 行高、
收气泡 `#2D2A45`、发气泡 `#7C5CFF`、洋红 1dp 边框、磨砂。

### 2.1 静态预览

- 打开“预览当前外观”，对话框标题“外观预览”，背景显示原图
  `VERIFYRICE0.9.1` 字样，收/发示例气泡使用当前配色、边框、字号与行高。
- 截图：`docs/screenshots/qa-0.21.0-preview.jpg`。

### 2.2 与实时修改联动

- 在同一页把“背景模糊”从“关”切到“强”，再次打开预览：背景文字与边框被
  明显抹平，只保留色块；气泡颜色/边框/字体不变。
- 证明预览读取的是当前快照而不是缓存的旧值；随后把模糊恢复为“关”，
  `ox_chat_theme.xml` 中 `background_blur=0`。
- 截图：`docs/screenshots/qa-0.21.0-preview-blur.jpg`。

### 2.3 稳定性

- 打开/关闭预览、切换模糊、返回聊天均无 FATAL/ANR；未修改用户消息与联系人。
- 无新增测试对象，无需清理。

## 3. 未覆盖 / 已知边界

- 预览是轻量示例，不是 `ChatMessageCell`；不显示媒体/文件/工具气泡、引用、
  头像、时间和长文本换行等真实消息结构。
- 磨砂气泡仍用透明度模拟，没有对气泡内容做真实高斯模糊。
- 自定义 TTF 字体在预览中的显示未单独截图验证（当前主题使用系统字体）。
- 原生模式不显示预览入口；预览只覆盖当前打开的作用域，不能并排对比多个作用域。
- 背景图/渐变的极端比例、极亮/极暗文字色只做了当前主题样本。
