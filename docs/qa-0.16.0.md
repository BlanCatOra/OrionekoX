# QA — alpha 0.16.0（按会话主题）

- 版本：`0.16.0`，versionCode **1609**
- 设备：emulator-5554（1080×2400，Android 14/34，`-gpu off`）
- 时间：2026-10-27 22:00–22:18（CST）
- 目标：补齐竞品“按会话（非仅按 Agent）主题”缺口：每个本地会话可单独覆盖外观，
  优先级为会话 > Agent > 全局，并提供可回退的清除入口。
- 版本规则：新增一项结构级外观能力（新作用域、存储与入口），按 minor 从 0.15.0 →
  **0.16.0**。

## 1. 新增能力

- `OxChatTheme` 新增按会话存储：
  `files/ox_chat_dialogs/dialog_<dialogId>.json`；`openDialog` / `closeDialog`，
  `forDialog` 读取顺序改为“会话覆盖 → Agent 覆盖 → 全局”。
- 聊天页右上角新增“会话外观”图标（仅本地 Agent 会话与本地群显示）；点击进入
  `OxChatAppearanceActivity` 的会话作用域页，标题为 `会话外观 · 名称`。
- 会话作用域页说明：“仅修改这个会话；未设置时跟随该 Agent 或全局外观”。
- 清除按钮在会话/Agent 作用域显示“清除覆盖并跟随上层”，只删除当前作用域文件；
  全局作用域仍为“重置为 Telegram 原生”。
- 会话覆盖与全局一样支持背景、气泡、边框、字体、行高、预设、JSON 与 `.oxtheme`
  导入导出。

## 2. 设备验证 — PASS（Agent 会话）

### 2.1 入口与继承

- 打开 `**Bold** Card`，右上角出现“会话外观”图标（[857,128][969,275]）。
- 进入后标题为 `会话外观 · 🤖 **Bold** Card`，首次打开显示从 Agent/全局继承的
  背景 `#101114`、收气泡 `#2D2A45`、发气泡 `#7C5CFF`、边框 `#FF2D95 1dp`、
  行高 1.4x。

### 2.2 覆盖与渲染

- 会话内把收气泡改为 `#E8F5E9`、发气泡改为 `#DCEBFF`；因继承文字色为白色，
  浅色气泡上文字不可读，随后在同一页把文字色改为 `#111111`。
- 返回聊天：长消息与工具提示气泡均变为浅绿 `#E8F5E9`、深色文字、保留洋红边框与
  背景图；发气泡为 `#DCEBFF`。
- 截图：`/tmp/bold_chat_readable.png`。

### 2.3 隔离

- 打开 `R2C Card`（无会话/Agent 覆盖）：仍是全局深色收气泡 `#2D2A45`、白字，
  未被 Bold Card 的会话覆盖影响。
- 截图：`/tmp/r2c_0160b.png`。

### 2.4 持久化与回退

- 设置会话覆盖后 `am force-stop` 并重启应用，重开 `**Bold** Card` 仍为浅绿气泡、
  深色文字；工具气泡同色，证明 `dialog_<id>.json` 持久化生效。
- 会话作用域点“清除覆盖并跟随上层”后返回聊天，恢复全局 `#2D2A45`、白字
  （截图采样 RGB 45,42,69）。
- 无 FATAL/ANR；未修改用户消息、Agent、记忆或工作区。

## 3. 未覆盖 / 已知边界

- 本地群入口：菜单条件包含 `OxGroupStore.isLocalGroup`，但模拟器两次在打开本地群时
  触发 Chromium/Vulkan 并导致 qemu 整机掉线（`-gpu off` 已知限制），因此群会话入口
  只完成代码路径，未做设备截图；待真机/GPU 环境复验。
- 会话覆盖从全局继承 `textColor`；若只把气泡改浅色而不改文字色，会出现低对比度。
  当前依赖页面内“检查文字对比度”提示，未自动改写用户的文字色选择。
- 预设/导入/导出在会话作用域复用同一套代码，未逐项重复截图（0.11/0.15 已覆盖全局）。
