# QA — alpha 0.10.0（外观对标第二批：按 Agent 主题、边框、字体、导出预览）

- 版本：`0.10.0`，versionCode **1409**
- 设备：emulator-5554（1080×2400，Android 14/34，`-gpu off`）
- 时间：2026-10-27 04:00–05:20（CST）
- 目的：实现第二轮报告与竞品调研确定的外观缺口，并验证按 Agent 隔离。

## 1. 新增能力

| 能力 | 说明 |
|---|---|
| 按 Agent 主题 | 智能体长按菜单新增「Agent 会话外观」；覆盖文件 `files/ox_chat_agents/agent_<tgId>.json`，只影响该 Agent；未覆盖时回退全局 |
| 应用到全部 Agent | Agent 外观页新增「将此外观应用到全部 Agent」，写入全局 |
| 背景样式 | 纯色 / 双色渐变 / 图片；渐变方向 3 种；背景不透明度、独立暗化层 |
| 气泡样式 | 实心 / 磨砂（磨砂降低有效 alpha）、边框颜色与 1–3dp 宽度、独立文字颜色 |
| 字体 | 聊天字体（系统/衬线/等宽/导入 TTF）、代码字体（系统/等宽/导入 TTF）、字号 0.9–1.3× |
| 可读性 | 按 WCAG 计算文字/气泡对比度并提示 |
| 导入/导出 | 竞品 JSON 导入预览（应用前确认，失败不写入）；导出当前主题 JSON；预设沿用全局目录 |
| 原生模式 | 「打开 Telegram 聊天主题」直达原生 ThemeActivity；一键重置 |
| 系统栏 | 自定义模式下同步状态栏/导航栏颜色与明暗图标 |
| 背景层 | `ThemeDelegate` 增加 `setOxWallpaperDrawable`，在聊天壁纸层替换为自定义 drawable |

## 2. 设备验证

### 2.1 按 Agent 隔离 — PASS

- 全局外观设为深色渐变、白色边框、白色文字、衬线字体。
- C2 单独覆盖：背景 `#F3F1F7`、收到气泡 `#FFFFFF`。
- 打开 C2：浅色背景、白色收到气泡、深色文字、白色 1dp 边框、衬线字体。
- 打开 R2C Card（无覆盖）：仍是全局深色背景/深色气泡/白色文字。
- 结论：按 Agent 快照与全局回退均生效。

### 2.2 边框 / 磨砂 / 字体 — PASS

- 自定义模式设置 `磨砂`、边框 `#FFFFFF` 1dp、文字 `#FFFFFF`、聊天字体 `衬线`。
- 聊天气泡显示白色细边框、圆角 18dp、半透明磨砂效果，中文衬线字体生效。
- 图片气泡同样带边框与圆角，不影响缩略图/双击/无红叹号。

### 2.3 背景与系统栏 — PARTIAL

- R2C Card 的全局深色背景完整覆盖，状态栏/导航栏同步深色。
- C2 的浅色背景生效，但仍能隐约看到 emoji 壁纸纹理；这是当前 `-gpu off` 模拟器下聊天壁纸层与列表层的合成结果，需要在真机/GPU 环境复验。
- 背景图片、渐变方向、暗化滑块的视觉差异未逐项截图验证。

### 2.4 导入预览与别名 — PASS

- `t991.json`（`in_bubble`/`out_bubble`/`corner_radius`/`font_scale`）导入后六项数值全部映射；0.9.1 已验证。
- 0.10.0 导入前弹出摘要（背景/气泡/透明度/圆角/字号/磨砂/边框），确认后才写入；非法 JSON 不改变现有主题。

### 2.5 原生模式 — PASS

- 原生模式显示「打开 Telegram 聊天主题」入口和「重置为 Telegram 原生」。
- 重置后聊天恢复原生壁纸/气泡，预设仍保留。
