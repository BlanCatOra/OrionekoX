# Design skills used for the Ox UI pass

Nine public agent skills were collected across three design areas. Each folder keeps
the original `SKILL.md` plus its text references (fonts/images/binaries omitted).

## 1. Mobile visual design
- `mobile-visual/ui-ux-pro-max` — UI/UX rule database (hierarchy, touch, motion, forms)
- `mobile-visual/mobile-app-ui-design` — onboarding flows, mobile layout, spacing
- `mobile-visual/mobile-app-design` — iOS/Android conventions, accessibility, touch targets

## 2. UX / interaction
- `ux-interaction/oil-ui` — design north star, composition, review protocol
- `ux-interaction/superdesign` — variants, component specs, visual exploration
- `ux-interaction/ui-audit` — hierarchy, fidelity, states, accessibility checklists

## 3. Design systems & controls
- `design-systems-controls/design-system` — token architecture, component states
- `design-systems-controls/james-design` — interface composition and prototyping
- `design-systems-controls/claude-design-skill` — design direction, anti-AI-slop rules

Sources and licenses: see `SOURCES.md`. The applied decisions are summarized in
`../docs/design-brief.md`.
